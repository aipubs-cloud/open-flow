# Changelog

All notable changes to Open Workflow Framework are documented here.

The project follows Semantic Versioning where versioned public contracts are concerned.

## [Unreleased]

### Added

- Foundational repository governance documentation.
- Explicit development and release expectations.
- Architecture, safety, workflow, schema, and verification documentation.
- Machine-readable contracts for core OWF primitives.
- Example workflow and policy fixtures.

### Changed

- Strengthened the repository foundation around evidence, verification, and bounded execution.

## [0.1.0] - 2026-09-05

### Added

- OWF-001 through OWF-010 workflow manifests.
- Reusable Copilot agents and skills.
- OWF-002 deterministic repository survey collector.
- Workflow and survey schemas.
- Initial CI and test harness.
- Git-native hooks and MCP extension boundaries.
