# OWF Schema Catalog

| Schema | Purpose |
|---|---|
| `workflow.schema.json` | Individual OWF workflow manifest |
| `registry.schema.json` | Root workflow registry |
| `agent.schema.json` | Reusable agent metadata and safety contract |
| `skill.schema.json` | Reusable procedural skill contract |
| `policy.schema.json` | Operating mode and capability policy |
| `hook.schema.json` | Hook lifecycle contract |
| `result.schema.json` | Structured execution result, evidence, and verification |
| `owf-002-survey.schema.json` | OWF-002 repository survey artifact |

## Contract rule

A schema describes structure, not truth. Passing schema validation proves structural conformity only. Semantic correctness, security, and execution success require additional evidence.
