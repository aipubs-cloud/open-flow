# Foundation Review Checklist

- [ ] Workflow, agent, skill, hook, and host responsibilities are separated.
- [ ] Public contracts have schemas.
- [ ] Examples are synthetic and safe.
- [ ] Executable claims have tests.
- [ ] Deterministic claims state assumptions.
- [ ] Error paths are represented.
- [ ] Capabilities are explicit and least-privilege.
- [ ] Destructive operations are opt-in.
- [ ] Secrets are excluded from artifacts and fixtures.
- [ ] Autonomous mode remains bounded.
- [ ] Existing workflows remain compatible.
- [ ] Host-specific claims are separated from core contracts.
- [ ] Changelog documents contract changes.
- [ ] CI can reproduce validation from a clean environment.
